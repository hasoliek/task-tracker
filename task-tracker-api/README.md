# Module 1 Task Tracker API

A minimal FastAPI REST API skeleton for the Module 1 Task Tracker learning project.

This module uses:

- Python
- FastAPI
- Pydantic
- Uvicorn
- python-dotenv

This skeleton includes only the application setup and a `/health` endpoint. CRUD endpoints are intentionally not included yet.
